# StockLite v9.3 iPhoneカメラ画質診断試験版

基準: v9.2。iOSカメラ画質診断パネルのみ追加。Android・IndexedDB・品目/履歴のロジックは変更しません。

## 使い方
1. JSONバックアップを取得。別オリジンのHTTPS試験環境へ配置。
2. iPhoneでスキャンを起動し「カメラ能力を確認」。映像解像度・fps・フォーカス・ズームの対応状況を記録。
3. 対応する場合だけ「連続AFを試す」「1.5倍ズームを試す」でJANを各5回比較。
4. 失敗時はカメラを維持し、従来設定で読み取る。

注意: SafariはfocusMode/zoomを公開しない場合があります。機能未対応は不具合とは限りません。ブラウザが自動でAFを実施している可能性があります。測定は手動で秒数を記録してください。実機試験は未実施です。
