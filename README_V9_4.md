# StockLite v9.4 iOS JANエンジン比較試験

基準：v9.3。iPhoneにD：ZXingフレーム単位（JAN-8/JAN-13）を追加。Android・IndexedDBのデータ形式は変更していません。

## 比較方法
1. 既存データをJSONエクスポートしてバックアップする。
2. 本番とは別オリジンのHTTPS環境で試験する。
3. A（html5-qrcode）とD（ZXingフレーム）で同じJANを5回ずつ読み、認識までの時間と成功回数を比較する。
4. カメラ診断のエンジン・コールバック数・エラーを記録する。
5. Dで不具合があればAに戻す。

## 注意
- Dは試験実装であり、実機での成功・高速化は未確認。
- 認識時間はカメラ起動後からの経過時間で、バーコードを映してからの厳密な時間ではありません。
- CDNからZXingを取得するため初回はネット接続が必要。
- テスト環境を本番と同一オリジンにするとIndexedDBを共有するため避けてください。
- v9.3の配布物にはmanifest.webmanifestとsw.jsが含まれないため、PWA更新動作はこのZIPだけでは保証できません。
