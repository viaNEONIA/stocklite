# StockLite v9.1 JAN速度比較試験版

- iPhoneのみ：JAN専用モード（EAN-8/EAN-13）、従来モード（EAN-8/EAN-13/QR）を選択できます。
- 解析頻度10fps/15fpsを切り替え、切替時にカメラを再起動します。
- JAN専用では読み取り枠を横長に変更します。
- 診断の「認識時間」はカメラ開始完了から最初の認識成功までの時間です。バーコードを映した瞬間からの時間ではありません。
- Android、在庫管理、IndexedDBのデータ形式は変更していません。
- 実機試験は未実施。まずJSONバックアップを取得し、別オリジンのHTTPS環境で試験してください。
- 比較は同じJANコード・同じ距離・同じ明るさで各設定5回程度行い、体感と診断時間を記録してください。
