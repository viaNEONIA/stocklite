# StockLite 試験計画

対象をmain診断/v9基準/ローカル統合候補で分ける。今回の文書作業では実機・権限・保存の新規試験を実施しない。既存の構文/模擬試験は再実行しTEST_RESULTSへ記録する。

## 環境と証跡

iPhone Safari、同端末ホーム画面PWA、Android Chrome。機種/OS/ブラウザ版/配信URL/BUILD/コミット/照明/印刷物/JAN形式/確認者/日時を記録する。現有ログにコミットSHAがない点はUNKNOWNとして残す。PC Node試験、実ブラウザ、実機を区別する。

## 速度の統一手順

コードを映像外へ置く→計測開始→合図で映す。v10.3では3秒カウントダウン後の合図から10秒計測する。カメラ起動とカウントダウンは別扱い。操作者の反応・移動時間を含み、映像外であった事実を自動検証はしない。

同一印刷物・照明・距離・角度をそろえ、JAN-8/JAN-13各条件10回以上。QRも別試験。条件順を交替し、一度に変える変数は1つ。認識後の緑表示を待った安定画像の試験と混ぜない。D/Eは対になる同一フレームの結果を優先し、異なる試行の単純成功率で原因を断定しない。

報告: 各回の生データ、不一致、タイムアウト、中断、未照合、正解数、10秒以内一致率、成功回のみ中央値、失敗も含む全試行中央値を明記。未検出時間は打切りであることを示す。中断は分母から除外して件数を別記。未照合は成功にしない。期待値誤入力を除外できないwrongは「期待値不一致」と記す。

暫定目標: JAN形式ごとに中央値3秒以内、10秒以内一致率90%以上、不一致0。ただし現有データは開始条件と版がそろっていない。全機能/全環境の受入、起動不具合の閉鎖、ユーザー承認が揃うまで正式採用・マージしない。
