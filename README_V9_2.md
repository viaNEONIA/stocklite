# StockLite v9.2 iOS JAN読み取り比較試験

## 目的
JANの読み取りが10秒以上かかる問題を切り分ける。v9の認識成功を維持し、Androidと在庫保存処理は変更しない。

## iOS比較モード
- A: html5-qrcode、10fps、カメラ解像度自動
- B: html5-qrcode、10fps、1280×720を希望（端末が別解像度を選ぶ場合あり）
- C: ネイティブBarcodeDetector、JAN-8/JAN-13のみ。API未対応なら起動失敗を明示。

## テスト
同じJAN-8/JAN-13を同じ照明と距離で各5回読み、認識時間と失敗回数を記録。QRはA/Bで検証。Android、在庫確定、IndexedDB、PWA再起動も再試験。

## 注意
診断の認識時間はカメラ起動完了からであり、バーコードを映した瞬間からではない。試験環境は本番とは別オリジンを推奨。実機試験は未実施。
